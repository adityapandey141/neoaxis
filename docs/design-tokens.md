## Typography

### Concept A — NeoAxis Precision
- **Primary font:** Inter (geometric sans-serif via `next/font/google`)
- **Usage:** All headings and body text; clean, contemporary feel

### Concept B — Medicine with a Cause
- **Display font:** Playfair Display (expressive serif via `next/font/google`)
- **Body font:** Inter (humanist sans pairing)
- **Usage:** Playfair for section headings, hero text, pull-quotes; Inter for body and navigation

## Logo Details
- Format: PNG with alpha transparency
- Original dimensions: ~1420×320 px
- Header usage: 160×36 px (Concept A), 140×32 px (Concept B)
- Footer: inverted via CSS `brightness-0 invert`
